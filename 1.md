To run (deploy) the Helm chart to your Kubernetes cluster:

### Step 1: Deploy the Chart
Run the following command in your terminal. This will install the deployment if it does not exist, or upgrade it if it does:

```powershell
helm upgrade --install gin-server ./charts/gin-server
```

---

### Step 2: Verify the Running Pods and Services
After deploying, verify that the resources have been created successfully:

```powershell
# Check the status of the pods
kubectl get pods -l app=gin-server

# Check the status of the services (including the LoadBalancer External IP)
kubectl get svc
```

---

### Useful Customizations:
If you want to override any settings defined in `values.yaml` without changing the file:

*   **Change the replica count on the fly**:
    ```powershell
    helm upgrade --install gin-server ./charts/gin-server --set replicaCount=3
    ```
*   **Change the image tag**:
    ```powershell
    helm upgrade --install gin-server ./charts/gin-server --set image.tag=v2
    ```
